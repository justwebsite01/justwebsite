## Shared findings

- **Shared stylesheet:** only six pages link `style.css`: blog, cheque-bounce, criminal-law, cyber-fraud-recovery, family-law, and succession-heirship. Other pages either embed their styling, use different CSS files, or are redirect/verification/offline documents. The homepage itself embeds a substantial style block and does not link `style.css`.
- **Color tokens:** `style.css` contains 108 literal hex/RGB/HSL color occurrences (69 distinct values, including the token definitions). Literal colors remain in component rules—for example base text/background colors, `#444`, and the WhatsApp green—alongside many literal `rgba()` values. Several pages also have substantial inline color usage; see the per-page counts.
- **Fonts:** the kids pages use DynaPuff/Laila instead of the three requested families; `leave-license-service.html` declares Cinzel; `offline.html` uses a system stack. Other pages mostly use the requested families, but declare them directly rather than consistently using the shared tokens.
- **Breakpoints:** `style.css` uses 1100, 768, and 480px, plus a 600px width breakpoint. Page-specific deviations include 560px (cyber), 600px (kids, estimator, offline, succession), 769px min-width (cheque), 768px min-width (criminal), 500/960px (Hindu calculator), 920px (stamp-duty estimator), and 620/980px (NIA tool). `prefers-reduced-motion` is a feature query rather than a width breakpoint.
- **Navbar/footer:** no page has the same navbar/footer tag-and-class structure as the proposed baseline. Several pages have no navbar or footer at all; the standalone estimators and NIA page omit the footer. The header tagline also varies. No consistent active/current nav link state was found.
- **WhatsApp:** the floating `.wa-float` component appears on 13 pages. It is absent from `blog.html`, `offline.html`, the Google verification file, and the three redirect wrappers.
- **Class overlap:** page-specific styles redefine names used in `style.css`, including `nav-brand`, `hero`, `active`, `btn-gold`, `btn-ghost`, `form-row`, `footer-grid`, `wa-float`, and `wa-tooltip`. This can change shared components depending on stylesheet order. `style.css` itself has repeated selector names for state/responsive variants; these are not all duplicate declarations.
- **Head template:** 12 pages have all six audited head items. The kids pages lack JSON-LD; `offline.html` lacks OG and JSON-LD; the three redirects have only viewport and canonical among the audited items; the Google verification file has none. Preserve existing JSON-LD during any later phase, but review its contact values against the requested branding before changing anything.
- **Branding / structured data:** the requested phone is `+91 8149135283` and email is `ajinkya.dhende@gmail.com`; existing visible/structured contact data frequently uses other phone numbers and personal email addresses. In particular, homepage and several pages' JSON-LD contain legacy contact values. These have been flagged only; no JSON-LD was modified.
- **External CSS duplication:** `site-consistency.css` is linked by many otherwise unrelated pages; `mobile-optimizations.css`, `style-msdr.css`, and `stylemacpv4.css` also contribute page-specific styles. These are additional cascade sources beyond `style.css`.

## Proposed canonical template

**`cyber-fraud-recovery.html`** is the least-divergent existing public-page template: it links `style.css`, has all audited head items including JSON-LD/favicon, includes navbar/footer/floating WhatsApp, uses token-based font declarations, and has only five inline style attributes and five literal color tokens in its page-specific CSS. Its page-specific CSS is largely scoped to `.cf-*` classes. It is not compliant as-is: its 560px breakpoint, branding/contact values, additional stylesheet link, and component markup still need review after approval.

No page is a clean canonical implementation today. The homepage is not the best baseline because most of its design system is duplicated inline, it does not link `style.css`, and its displayed/schema contact details differ from the requested branding.
